## 功能要求
1. 手机拍照识别各部位方阻数据；或上传 Excel 提取方阻数据。
2. 支持固定热力分布色标量程，例如 8–14 Ω/□。
3. 异常点规则：超出单片平均方阻 ±10% 时，在热力图上红色加粗显示；阈值可设置。
4. 支持单片展示与多片汇总展示。
5. 最新热力逻辑：**方阻越低，热力越高；方阻越高，热力越低。**
6. 统计：
   - 平均方阻
   - 最大值
   - 最小值
   - 不均匀性 = (Rmax-Rmin)/(Rmax+Rmin) × 100%
   - 均匀性 = 100% - 不均匀性

## OCR 拍照识别配置

### 浏览器预览版（preview.html）— 百度OCR高精度识别
使用百度智能云 OCR API，识别准确率95%+，配置步骤：

1. **注册百度智能云**：访问 cloud.baidu.com，注册/登录账号
2. **开通文字识别**：控制台 → 文字识别 → 领取免费资源（每天1000次免费）
3. **创建应用**：控制台 → 文字识别 → 创建应用，获取 **API Key** 和 **Secret Key**
4. **填入密钥**：用浏览器打开 preview.html → 录入数据 → 在「百度OCR密钥配置」卡片中填入API Key和Secret Key → 保存
5. **开始使用**：选择图片 → 旋转到正确方向 → 全图识别或框选区域识别 → 核对数据 → 批量保存

### 功能说明
- **图片旋转**：左转/右转90°，调整图片方向
- **全图识别**：对整张图片做OCR，自动按每12个数字拆分为多片玻璃
- **框选区域识别**：拖拽框选一片玻璃的数据区域，单独识别，可多次框选累加
- **图片预处理**：自动放大2倍 + 灰度化 + 对比度增强，提升识别率
- **批量保存**：识别结果逐片核对后一键全部保存

### 微信小程序版（需微信开发者工具）
OCR 通过微信云函数 + 腾讯云 OCR 实现，配置步骤：

1. **注册小程序**：在 mp.weixin.qq.com 注册小程序，获取真实 AppID
2. **开通云开发**：在微信开发者工具中，点击「云开发」按钮开通
3. **替换 AppID**：将 project.config.json 中的 `touristappid` 改为你的真实 AppID
4. **替换云环境ID**：将 app.js 中的 `your-env-id` 改为你的云环境ID
5. **部署云函数**：
   - 在开发者工具左侧找到 `cloudfunctions/ocr` 文件夹
   - 右键 → 「在终端中打开」→ 运行 `npm install`
   - 右键 → 「上传并部署：云端安装依赖」
6. **配置腾讯云密钥**（用于 OCR 识别）：
   - 前往 console.cloud.tencent.com 开通 OCR 服务（有免费额度）
   - 获取 SecretId 和 SecretKey
   - 在云开发控制台 → 云函数 → ocr → 环境变量中添加：
     - `TENCENT_SECRET_ID` = 你的 SecretId
     - `TENCENT_SECRET_KEY` = 你的 SecretKey
