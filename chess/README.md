# 狗哥下象棋

面向家人的中国象棋应用：原生微信小程序、权威对战服务，以及共用同一服务的本地浏览器试玩界面。

## 现在就试玩

本机双击：`/Users/kunpengwu/Desktop/Games/启动狗哥下象棋.command`。

或在终端运行：

```sh
cd /Users/kunpengwu/Desktop/Games/gouge-xiangqi
npm ci
npm start
```

打开 [本地棋馆](http://127.0.0.1:8787)。首次填写称呼创建**本地开发账号**，即可与本地 AI 下棋。尚未填写 DeepSeek 密钥时，页面会明确显示使用本地引擎。

测试玩家对战：在两个独立浏览器窗口（普通窗口和无痕窗口，或两个不同浏览器）分别创建开发账号，在同一张棋桌入座，双方准备后开局。第三个独立浏览器账号可以旁观。开发账号不是微信身份；本地试玩通过独立聊天接口验证同桌文字与互动表情。

本机已验证的 Node 版本为 25.9.0。运行依赖只有 `ws`；不需要安装模型权重或单独的棋类引擎程序。

## 已实现的功能

- 中国象棋合法走法、将军、将死、困毙、WXF 长将长捉、真假根和自然限着。
- 双方同意悔棋，撤回自己上一手及对方随后一手；已经消耗的时间不退还。
- 各自累计思考时间；普通逐手限制、总额度用尽转逐手限制、两者组合及快棋。
- 超时由服务端自动走合法棋；页面关闭或掉线不重置时钟。
- 五档本地搜索及可配置的 DeepSeek 选着，非法输出、失败、超时和迟到结果有兜底。
- 固定六桌、双方准备、规则确认、旁观、状态同步、断线恢复、认输及再来一局。
- 协商和棋及自然限着提和。AI 的协商和棋采用明确的家庭策略：同意玩家申请。
- 微信登录、主动填写头像昵称、头像上传、昵称修改。
- 首页继续本人对局；保存默认计时和落子声音偏好。
- 手持棋子移动与落子动画；吃子击飞淡出，对局主屏不显示棋袋。
- 紧凑对局主屏，直接认输与离开，底部打开同桌聊天与圆形互动按钮；棋谱、计时详情与其余辅助操作集中在设置页。
- 离开进行中的棋局后计时继续；成功创建或加入另一盘时，旧的未完成对局自动退出并判本人负。等待开局的旧桌只退出座位。
- 同桌棋手及旁观者文字交流：最近 50 条记录、每条最多 200 字、带昵称的大字漂浮字幕；握手、点赞、臭棋、哭鼻子、大笑和白旗六种互动。白旗不触发认输。
- 对局、截止时间与用户资料持久化，服务重启后恢复。敏感会话仅在后端保存，不发送给客户端。

聊天以独立序号同步，不依赖棋局 WebSocket。客户端每 3 秒串行刷新；发送成功立即显示本人字幕。首次打开只读取历史，进入设置或后台暂停接收，返回重新读取。正式云函数从微信身份核验同桌成员，仅写独立聊天集合，文字安全检查失败时不发送。

## 配置外部服务

复制 `.env.example` 为 `.env`，修改本地文件，不要把密钥发到聊天或提交源码仓库。

| 配置 | 作用 |
|---|---|
| `DEV_MODE=true` | 本地开发账号；默认只监听本机 |
| `HOST` / `PORT` | 默认 `127.0.0.1:8787` |
| `ALLOW_LAN_DEV=true` | 仅在可信局域网调试时显式允许非本机监听 |
| `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` | 服务端 DeepSeek 选着；默认模型可修改 |
| `WECHAT_APP_ID` / `WECHAT_APP_SECRET` | 真实微信登录；密钥仅在后端 |
| 客户端 `chatFunction` | 正式聊天云函数名，默认 `gouge-chess-chat` |
| `PUBLIC_BASE_URL` | 正式环境 HTTPS 服务地址 |
| `DATA_DIR` | 后端数据目录，默认 `./.data` |

局域网开发示例（只在需要时执行）：

```sh
HOST=0.0.0.0 ALLOW_LAN_DEV=true npm start
```

客户端服务地址需改为电脑的局域网 IP，不能在手机上使用电脑的 `127.0.0.1`。正式环境设 `DEV_MODE=false`，配置 HTTPS/WSS、真实 AppID 和微信合法域名。当前实现使用单进程与本地 JSON 持久化，适合家庭规模；多进程部署需要共享状态及单一裁决机制。

## 验证

```sh
npm test
npm run build
node scripts/browser-acceptance.mjs
```

`npm test` 包含规则、计时、服务端、AI 与微信客户端模拟接口测试。微信客户端的模拟接口测试不代表真实微信接口成功。

`npm run build` 校验 JavaScript、JSON、页面与组件依赖，并使用本机微信开发者工具中的官方 WXML/WXSS 编译器。编译器不在默认安装路径时，可设置 `WECHAT_COMPILER_DIR`；找不到时报告模板编译“未验证”。构建报告在 `dist/build-report.json`。

浏览器验收脚本在隔离临时数据目录中启动服务，使用本机 Chrome 和已提供的 Playwright 运行环境；不读取 `.env` 的真实密钥，也不调用真实外部服务。其他电脑可通过 `PLAYWRIGHT_MODULE` 指定已安装的 Playwright 模块路径。证据保存在 `verification/`，具体结果见 [验证记录](docs/VERIFICATION.md)。

## 规则边界

详见 [规则与覆盖说明](docs/RULES.md)。循环算法通过 173 个作者来源回归条目和 46 个真假根条目；条目数不等同于官方棋图数量。

全套官方 110 幅图尚未逐图人工校对，复杂理论残局未接完整残局表库。自动循环裁决替代赛事现场裁判流程。超时代走、同意悔棋及额度用尽转逐手是本产品的家庭玩法。
