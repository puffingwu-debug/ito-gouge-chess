# 对局页面整理

2026-10-10。对局页已按用户要求从语音改为文字交流。

## 页面职责

主屏用于下棋和文字交流：对手信息、棋盘、本人信息、当前回合、认输与离开、底部同桌聊天、圆形互动按钮及设置入口。删除上下棋袋，保留手持落子与吃子击飞淡出。

设置页承载本局计时详情、规则、棋谱和其余辅助操作，并保留已有资料及默认偏好。进入设置不离桌、不结束棋局、不重置时钟；返回时同步权威棋盘。准备及协商请求只在主屏保留必要的短提示。

认输在确认后立即结束棋局。进行中点击离开仅返回，计时继续；成功创建 AI 对局或加入另一棋桌时，服务端自动退出旧的未完成对局并判本人负。旧等候桌只释放座位，不判负。重新进入原棋局或单纯旁观不会触发判负；新局校验失败不影响旧棋局。

## 视觉约束

保留木色棋盘及红黑棋子：纸色 `#f6f0e5`、木色 `#d8b889`、深墨 `#252c26`、次要文字 `#716a5f`、红色 `#a8322e`、深绿 `#2f5648`。正文沿用苹方系统字，棋子沿用宋体，计时数字保持稳定宽度。

缩小玩家信息和边距，以棋盘为视觉中心。聊天和互动按钮保持至少 44px 的触摸高度；底部考虑安全区，小屏棋盘按可用高度收缩。

## 文字与互动

底部“同桌聊天”打开最近50条记录与输入框，每条保留发送者昵称。新消息以22px大字字幕出现在棋盘上；首次加载历史不重放。长文在三行窗口内完整滚动，字幕不拦截棋盘点击。

点击或长按圆形🙂按钮弹出六种互动：🤝握手、👍点赞、🙈臭棋、😭哭鼻子、😂哈哈大笑、🏳️白旗。选择后发到同桌消息流；白旗只是互动，正式认输仍需点击认输并确认。

棋手和已进入该桌的旁观者可以交流；AI对局及离桌后的历史成员不可发消息。聊天独立刷新，不以棋局实时连接状态作为入口门槛。页面隐藏后暂停接收并清字幕；切换账号清旧消息。聊天时计时继续。

## 验证目标

无棋袋、无麦克风权限或语音按钮；聊天与互动可在断线后棋局轮询模式使用；六表情带昵称且白旗不认输；消息迟到不改棋盘/时钟，失败重试不会重复发送；设置与棋盘往返保持同一棋局。实际验收记录见 `verification/chat-acceptance-20261010.json`。
