# 狗哥下象棋 · 界面设计

新建家庭棋类应用。优先手机近距离阅读，温暖、安静、熟悉的实体棋盘观感。
本地浏览器界面用于立即试玩，原生微信客户端沿用同一套视觉。
没有既有品牌素材，使用产品名称作为文字标识，不编造外部品牌资产。

设计取值：布局变化3、动效2、密度5、素材依赖1、既有品牌保留1。
布局稳定：三项导航，棋盘为视觉中心；动效仅选中、落子和状态切换；对局信息随屏幕尺寸移到侧栏或下方。

颜色：纸 #f6f0e5、棋盘木 #d8b889、红 #a8322e、墨 #252c26、绿 #2f5648。
标题与棋字采用本机宋体系列；正文采用系统中文无衬线。
4px间距基准，按钮至少44px，棋盘圆角12px、卡片16px、按钮8px。
仅棋子与浮层有必要的层级阴影。尊重系统减少动画偏好。

2026-10-08 扩展：保留现有导航、纸木配色、宋体棋字和棋盤中心布局，动效提高至 7，其他密度与素材取值沿用。主要动作是一只手拿起棋子、平移并落下；吃子沿击飞路径进入顶 / 底收子袋。浏览器使用轻量 SVG 手与 Web Animations，原生使用视图形状与位置过渡；不加入大动画库。吃子序列从权威棋谱生成，镜像视角只改变显示。短快棋下点击棋盘可直接结束展示动画，开始当前回合操作。
