# ITO 工具与狗哥下象棋

保存 2026-10-11 上传到微信开发者平台的合并小程序源码，并包含象棋后台、云函数与自动化测试。

## 目录

- `wechat-app/`：本次上传的完整合并小程序，包含 ITO 方阻分析、玻璃裁切及象棋分包。在微信开发者工具中导入此目录。
- `chess/`：象棋开发工程，包含规则引擎、后台、独立小程序、浏览器试玩、聊天云函数、部署模板和测试。
- `docs/`：本次隐私整改说明及上传版本信息。

微信 AppID、云环境 ID 是服务标识。AppSecret、DeepSeek 密钥、真实用户数据、日志、缓存及开发者个人配置均不提交。已有部署中的密钥继续保留在服务器配置中。

## 本地运行象棋试玩

需要 Node.js 22.9 或以上。

```sh
cd chess
npm ci
cp .env.example .env
npm start
```

打开 http://127.0.0.1:8787 。本地账号仅用于开发。

## 验证

从仓库根目录运行：

```sh
cd chess
npm ci
ITO_HOST_ROOT="$(cd ../wechat-app && pwd)" npm test
npm run build
npm run build:host -- ../wechat-app
```

WXML/WXSS 编译需要安装微信开发者工具；非默认路径可通过 `WECHAT_COMPILER_DIR` 指定官方编译器目录。

## 当前上传版本

版本为 `2026.10.11`，包含隐私接口整改、隐私授权控制及隐私指引入口。提交审核前仍需在微信后台补全“用户隐私保护指引”。上传成功不代表审核或正式发布完成。

同桌交流使用文字聊天与互动表情。OCR 拍照识别入口目前关闭；Excel 自动解析未实现。原目录内较早的 README 和部署文档保留作为历史资料，当前状态以本说明和实际代码为准。

云函数及象棋后台需独立部署，源码仓库不会自动配置线上环境。已有线上环境无需因 Git 备份重新创建。小程序开发工具的个人配置可在本机创建，不能提交密钥。

旧 OCR 辅助服务及 OCR 云函数的硬编码百度凭据已在此 Git 副本中改为从 `BAIDU_API_KEY`、`BAIDU_SECRET_KEY` 环境变量读取，浏览器旧预览页的密钥预填也已移除。配置模板见 `wechat-app/.env.example`；不会自动读取模板。这些处理未改动已上传的原微信工程。
